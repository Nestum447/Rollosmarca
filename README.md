📸 How many rolls are in an image, Camera, Container?


It sounds like a simple question.

But when images contain a large number of rolls, manually counting and recording them can become:

❌ Time-consuming
❌ Repetitive
❌ Prone to counting errors
❌ Difficult to document
❌ Difficult to convert into structured data

💡 So I decided to turn the image into data.

I developed an Interactive Roll Counter, a web application built with React that transforms a visual counting process into a digital and structured workflow.

🚀 How does it work?

📷 1. Upload an image
Select an image directly from your device.

🎯 2. Mark the rolls
Click on each roll directly on the image.

🔢 3. Count in real time
The application automatically tracks every marked point and displays the total count.

📍 4. Capture X,Y coordinates
Each roll is recorded with its position within the image.

📊 5. Export the data
Download all records as a CSV file for further analysis in Excel or other tools.

🔄 From manual to digital

BEFORE
📷 Image → 👀 Manual counting → ✍️ Manual recording

AFTER
📷 Image → 🖱️ Digital marking → 🔢 Automatic counting → 📊 Structured data

The goal wasn't simply to build a React application.

The goal was to transform a manual identification and counting process into a digital, measurable and structured workflow.

.📸 Contador Interactivo de Rollos
Este proyecto es una aplicación en React que permite cargar una imagen, marcar puntos sobre ella con clics, contar la cantidad de puntos marcados (rollos) y exportar las coordenadas en un archivo CSV.

Sitio Web
https://nestum447.github.io/Rollosmarca/

🚀 Funcionalidades
Subir una imagen desde el dispositivo.

Hacer clic sobre la imagen para marcar puntos (rollos).

Visualizar en tiempo real el conteo de rollos marcados.

Ver una tabla con las coordenadas (X, Y) de cada punto.

Exportar los datos en formato CSV.

🖼️ Vista previa
Sube una imagen.

Haz clic sobre la zona donde está cada rollo.

Observa el conteo en pantalla y la tabla con coordenadas.

Descarga el archivo rollos.csv con los datos registrados.

🛠️ Tecnologías utilizadas
React (con Hooks: useState, useEffect, useRef)

react-csv para exportar datos
